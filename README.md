# Исследование: Классификация текста Трансформерами vs Традиционный ML

Научно-практическое исследование в рамках задачи анализа тональности текста (*Sentiment Analysis*). Проект сравнивает эффективность современных архитектур глубокого обучения (на примере `DistilBERT`) с классическими частотными алгоритмами (`TF-IDF + Logistic Regression / Naive Bayes`).

---

# 📌 Аннотация

Цель проекта — доказать или опровергнуть гипотезу о том, что механизм `Self-Attention` архитектуры `Transformer` справляется с пониманием сложного контекста лучше, чем традиционные методы обработки естественного языка, игнорирующие порядок слов.

В качестве набора данных используется датасет `IMDB Reviews`.

---

# 🔬 Структура исследования

Проект выполнен в формате интерактивного `Google Colab` блокнота и включает 8 этапов:

1. Теоретическое и математическое обоснование механизма `Attention`
2. Разведочный анализ данных (`EDA`) и визуализация распределений
3. Векторизация и обучение базовых моделей (`Baseline`)
4. Fine-tuning предобученной языковой модели `distilbert-base-uncased`
5. Сравнительный анализ точности (`Accuracy`) и матриц ошибок
6. Интерактивный модуль для тестирования моделей на пользовательских текстах

# 📊 Главные выводы

- При малых объемах данных классические алгоритмы (`Logistic Regression`) показывают высокую конкурентоспособность.

- При увеличении обучающей выборки `Transformer` уверенно обходит бейзлайны, так как начинает распознавать сложные лингвистические конструкции (`сарказм`, `отрицания`).

- Обучение глубоких нейросетей требует значительных вычислительных ресурсов (`GPU FP16`), тогда как традиционные методы обучаются за секунды на `CPU`.
